# Project: Personal Introduction Program

## 📖 Project Overview
The goal of this project is to create a program that asks for a user's name, age, and hobby, and then displays a friendly welcome message with their information.

## 📂 Code Structure
* `README.md` - Complete project documentation.
* `personal_intro.py` - The main script containing the user input and print logic.
* `requirements.txt` - Lists project dependencies.
* `screenshot.png` - Visual proof of the working program.

## 🛠️ Technical Details
This program uses basic Python data structures and functions:
* `input()` is used to capture text data from the user.
* Variables (`name`, `age`, `hobby`) store the answers.
* `print()` combined with formatted string literals (f-strings) outputs the customized, friendly message.

## 🧪 Testing Evidence
**Test Case:**
* Input: Name: "Alex", Age: "25", Hobby: "rock climbing"
* Expected Output: 
  "Welcome, Alex!"
  "It's great to meet a 25-year-old who loves rock climbing."
* Result: Passed.
